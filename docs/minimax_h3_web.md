# MiniMax H3 Web 使用说明

手机 / 电脑浏览器可用的 **MiniMax H3 生成控制台**（`scripts/minimax_h3_web.py`，端口 `:8191`）。
两级结构「项目 → 分镜」，两种生成模式（文生视频 / 参考生视频），**项目内素材库**，串行队列，
产物管理，以及把已生成片段拼接成片的**剪辑时间线**。

- 界面语言：中文（mobile-first，窄屏自动单列）
- 无第三方依赖：Python 标准库 + 原生 HTML/JS（生成/渲染在子进程里跑 `comfyenv`）
- 单页应用，路由为 URL hash：`#/`（项目列表）、`#/p/<项目id>`（项目）、`#/p/<项目id>/edit`（剪辑）

## 1. 打开、启动与状态

### 1.1 访问地址与登录

- 本机：<http://127.0.0.1:8191/>
- 局域网：`http://<本机IP>:8191/`
- 外网（frp 映射）：`http://47.100.49.187:8110/`（`home_minimax_h3` 代理）

使用 **HTTP Basic 认证**：用户名任意，密码为 `scripts/minimax_h3_web.py` 里的
`DEFAULT_PASSWORD`（当前 `aiakos-ref2v`，启动时可用 `--password <新密码>` 修改）。
浏览器会弹一次登录框，之后本会话免输。

### 1.2 启动 / 停止

```bash
# 启动（后台，默认 0.0.0.0:8191）
python3 ~/MiniMax-H3-Deploy/scripts/minimax_h3_web.py --start
python3 ~/MiniMax-H3-Deploy/scripts/minimax_h3_web.py --status
python3 ~/MiniMax-H3-Deploy/scripts/minimax_h3_web.py --stop
```

- 日志：`~/MiniMax-H3-Deploy/minimax_h3_web.log`
- 数据目录：`~/MiniMax-H3-Deploy/.h3ref2v/`（分镜、项目、时间线序列）

### 1.3 依赖：ComfyUI 引擎

生成需要 **ComfyUI 引擎在 `:8188` 运行**（`scripts/start-comfyui-for-minimax-h3.sh`）。
顶部状态条会显示 `ComfyUI 在线 / 离线`：

- 生成结束后模型**常驻显存**，以便下次快速生成；
- 需要腾显存时点右上角 **「释放显存」**（会停止 ComfyUI，下次生成需冷启动，约多 1~2 分钟）。

也可以用系统面板（`http://<本机IP>:8200/`）的 **「MiniMax H3」卡片**启停本控制台，卡片的
「面板 :8191」链接直达本页。

## 2. 项目

打开首页即项目列表（卡片显示项目名、分镜数、封面缩略图）。

- **新建项目**：顶部「新建项目」输入名称 → 「创建」。
- **进入项目**：点项目卡片。
- **进入项目后**右上角有：`剪辑`（进入时间线）、`改名`、`删除`、`全部项目`。
- **删除项目**弹窗可选：
  - 勾选「同时删除产物」→ **purge**：删除项目、分镜记录与该项目的视频文件（不可恢复）；
  - 取消勾选 → **detach**：项目内分镜转回「默认项目」，视频文件保留。
- `默认项目`（id `default`）是内置项目，不能改名 / 删除。

> 建议按作品/题材建项目，产物按 `output/<项目id>/<模式>/<分镜id>.mp4` 归档，互不干扰。

## 3. 新建分镜

进入项目后，项目名下方「N 个分镜」右侧点 **「添加分镜」**：弹窗输入**分镜名**（项目内唯一，≤60 字符），
确认后才会展开「新建分镜」表单。填好后点「提交」，表单收起，分镜记录里出现该分镜的进度。
分镜名在「分镜记录 / 分镜详情」中与分镜 id 一并显示。

表单内容如下：

### 3.1 模式：文生视频（t2v）

- 顶部下拉选 **「文生视频」**。
- 只填提示词即可（纯文本生视频）；
- 可选从**素材库**选 **首帧** / **尾帧**（各一张图片）做画面锚定。

### 3.2 模式：参考生视频（ref2v）

- 模式选 **「参考生视频」**，然后从**素材库**选参考素材：
  - **参考图**（≤9 张）、**参考视频**（≤3 段）、**参考音频**（≤3 段）；
  - 至少选 1 个参考素材。
- **参考视频**额外支持 **「选择产物」**：从本项目**已生成的片段**（产物）中挑选，与素材库视频
  混用，合计仍 ≤3 段。
- 选好后在素材右侧标签按钮点一下，会把引用标记（如 `<Picture 1>` / `<Video 1>` / `<Audio 1>`）
  插入提示词光标处，用于指明「哪张图 / 哪段视频」参与；不插入则默认整体参考。

### 3.3 提示词与「提示词优化」

- 在提示词框写画面描述（中文/英文均可）。
- 点 **「提示词优化」**：调用云端大模型，把你的描述扩写为**电影级分镜提示词**
  （镜头运动、景别、光线、氛围、画质关键词，并结合已选择的参考素材种类）。
- 弹窗中可 **「复制」** 或 **「替换输入框」**（用优化结果覆盖原提示词）。
- 未配置 API key 会提示去 `~/.config/h3ref2v/llm.conf` 配置（见 §7）。

### 3.4 参数

| 参数 | 说明 |
|---|---|
| 时长(秒) | 1–15，生成视频的目标秒数（实际帧数按模型 24fps 规则就近对齐） |
| 步数 | 1–50，采样步数；越高质量越好、越慢（默认 8） |
| seed | 留空 = **随机**；填数字可复现 |
| 画幅 | 16:9 / 9:16 / 1:1 等 |
| 分辨率(MP) | 0.2–0.8 百万像素（默认 0.4） |
| 参考图缩放 | 仅 ref2v：`match`（快）/ `max`（保真） |

### 3.5 素材库

项目页中「分镜记录」上方的 **「素材库」** 通栏卡片，用于在项目内集中上传、复用素材。

- **上传**：填「素材名称」→ 选文件 → 「上传素材」。类型按扩展名自动识别
  （图片：png/jpg/jpeg/webp/bmp/gif；视频：mp4/mov/webm/mkv/avi；音频：mp3/wav/m4a/aac/flac/ogg）。
- **命名唯一**：名称在**项目内唯一**（重名会被拒绝），最长 60 字符。
- **选择素材**：新建分镜时，参考图/视频/音频、首帧/尾帧的「选择素材」都**只从本素材库中挑选**，
  不再直接上传文件（首帧/尾帧单选，其余可多选）。
- **删除**：删除前会检查分镜记录；若有分镜用到该素材，会列出这些分镜并提示「引用将失效」，确认后才删除。
- 存储：`.h3ref2v/projects/<项目id>/materials/<素材id>.<后缀>`。
- 缩略图：图片素材列表与「选择素材」用 `/thumb` 加载自动生成的小图（宽 ≤480px，缓存于 `thumbs/`），
  避免大图直接加载变慢。

### 3.6 提交 / 重置

- **提交**：先弹确认框（项目、分镜名、类型、时长、步数、素材、提示词摘要），确认后上传并排队，表单收起。
- **重置**：弹确认框后清空表单并恢复默认（t2v / 5s / 8 步 / 随机 seed / 16:9 / 0.4MP），**保留分镜名**。
- **取消**：收起「新建分镜」表单并清空，放弃本次添加。
- 队列**全局串行**（一次只跑一个生成分镜，保证显存安全）。

## 4. 素材库 / 分镜记录

项目页从上到下依次为两张通栏卡片：

- **素材库**：见 §3.5。
- **分镜记录**：该项目的历史分镜，每条包含**分镜名 + 分镜 id**、类型、素材、用时、阶段与状态，以及**产物缩略图**
  （点缩略图即放大播放）；没有产物时显示同尺寸占位框（进行中/排队为闪烁框＋进度条，取消/失败等为静态框）。
  每行按钮：
  - **详情**：查看完整参数（分镜名/时长/步数/seed/画幅/分辨率）与**素材预览**（图/视频/音频，可播放）。
  - **复用**：弹窗**预填原分镜名**，需改成新的分镜名（确认时查重，重名会提示且弹窗不关），通过后把该分镜的
    参数与素材**一键回填**到「新建分镜」表单（按素材文件匹配素材库；素材已删除的会被跳过；
    **seed 留空 = 随机**，避免复现同一段，需手动改参数后自行提交）。
  - **取消 / 删除**（删除会连同其产物视频一起删除）；进行中的可**取消**（会同时让 ComfyUI 中断当前采样）；
    已取消/失败/中断的可点 **生成** 直接原地重新提交；已完成的有 **查看**（播放产物）。
  - 卡片右上角 **「剪辑」** 进入时间线（§5）。
- **诊断日志**（折叠，在分镜记录卡内）：实时生成日志，排障用。
- 状态含义：排队中 / 进行中 / 已完成 / 失败 / 已取消 / 已中断（web 重启导致，重新提交即可）。

## 5. 剪辑成片（时间线）

「分镜记录」卡片右上角 **「剪辑」** 进入 `#/p/<项目id>/edit`。把该项目里已生成的片段拼接成一个成片。

1. **添加片段**：下方「添加片段」点缩略图，依次加入时间线（可重复加同一段）。
2. **排序**：拖拽每段左侧的 **`≡`** 手柄；或用 **▲ / ▼** 微调；**✕** 移除。
3. **转场**：相邻片段之间的「转场」下拉，四种：
   - `硬切`（无重叠）、`黑场渐隐`、`交叉溶解`、`推进/滑动`；
   - 非硬切可选转场时长 `0.3 / 0.5 / 0.8 / 1.0 / 1.5s`。
4. **成片设置**：`成片画幅`（原始 / 2.39:1 / 16:9 / 9:16 / 1:1 / 4:3 / 3:4，按首段中心裁切统一）、
   `片头淡入` / `片尾淡出`（0–3s）。
5. **保存**：把时间线写入 `output/<项目id>/edit/` 同级的序列文件（项目内 `edit.json`）。
6. **预览/导出** → 确认后提交渲染（排队执行）。渲染进程实时显示进度与日志。
7. **成片**列表出现结果后可播放；左下角红色按钮删除成片（连同文件）。

- 输出：`~/MiniMax-H3-Deploy/output/<项目id>/edit/<分镜id>.mp4`
- 成片**不计入**项目分镜数，也不会出现在「分镜记录」里（按 `mode=edit` 过滤）。
- 渲染为纯 CPU（PyAV/libx264），逐帧拼接、按首段尺寸裁幅、逐段音频对齐 + 硬切处防爆音淡化。

## 6. 素材规格与限制

| 项目 | 规格 |
|---|---|
| 素材名称 | 项目内唯一，≤ 60 字符，不含斜杠 |
| 参考图 | ≤ 9 张（从素材库选） |
| 参考视频 | ≤ 3 段；**建议每段 2–15s、合计 ≤ 15s**（素材库素材或本项目产物） |
| 参考音频 | ≤ 3 段；**建议合计 ≤ 15s**（从素材库选） |
| 首帧 / 尾帧 | 各 1 张图片（t2v 可选，从素材库选） |
| 时长 / 步数 | 1–15s / 1–50 |
| 输出帧率 | 24 fps（时长会就近对齐到模型支持的帧数） |

## 9. 常见问题

- **顶部显示「ComfyUI 离线」**：生成前先启动引擎
  （`bash ~/MiniMax-H3-Deploy/scripts/start-comfyui-for-minimax-h3.sh` 或系统面板 Qwen/ComfyUI 卡片）。
- **分镜失败 / 显存不足**：点「释放显存」停止 ComfyUI 后重试；避免与其他大模型服务同时占用显存。
- **分镜显示「已中断」**：web 服务重启会把运行中的分镜标记为中断，重新提交即可。
- **提示词优化失败**：检查 `llm.conf` 的 key/网络；未配置时手动写提示词亦可。
- **素材被拒**：名称为空/重名/含斜杠/超长，文件类型不支持，或素材文件已被删除；
  参考图/视频/音频数量超限（§6），或 ref2v 未选择任何素材、t2v 选择了参考素材。
- **分镜名被拒**：为空、超长（>60 字符）或与本项目内已有分镜重名（弹窗会提示，改个名字再确认）。
- **手机访问**：直接用局域网 `http://<IP>:8191/`（或 frp `8110`），页面为响应式布局。

## 10. 进阶：HTTP API 速查

同 Basic 认证；`<user>` 任意。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/state` | ComfyUI 状态、显存、当前/排队分镜 |
| GET | `/api/projects` | 项目列表 |
| POST | `/api/projects` | 新建项目 `{name}` |
| POST | `/api/projects/<id>/rename` / `delete` | 改名 / 删除 `{name}` 或 `{mode:purge|detach}` |
| GET | `/api/jobs?project=<pid>` | 分镜列表（含参数、分镜名、素材） |
| GET | `/api/jobs/<jid>` / `/log?offset=` | 单分镜详情 / 增量日志 |
| POST | `/api/jobs/<jid>/cancel` / `delete` | 取消 / 删除记录 |
| GET | `/api/outputs?project=<pid>` | 产物列表 |
| GET | `/api/materials?project=<pid>` | 素材库列表 |
| POST | `/api/materials` | 上传素材（multipart：project/name/file） |
| POST | `/api/materials/<pid>/<mid>/delete` | 删除素材 |
| POST | `/api/output/delete` | 删除产物 `{rels:[...]}` |
| POST | `/api/optimize` | 提示词优化 `{prompt, counts}` |
| POST | `/api/run` | 提交生成（multipart：project/name/mode/prompt/dur/steps/aspect/megapixels +
  素材：ref_image/ref_audio/first_frame/last_frame 为素材库 id；ref_video 为素材库 id 或
  `clip:<产物相对路径>`；`name` 为分镜名，项目内重名返回 409） |
| GET/POST | `/api/sequence?project=<pid>` | 读取 / 保存剪辑序列 |
| POST | `/api/edit/render` | 提交成片渲染 `{project}` |
| POST | `/api/edit/delete` | 删除成片 `{id}` |
| GET | `/media/<jid>/<file>`、`/material/<pid>/<file>` | 分镜素材 / 素材库文件回放 |
| GET | `/thumb/<pid>/<file>` | 图片素材缩略图（首次访问自动生成并缓存，宽 ≤480px） |
| GET | `/files/<rel>` | 产物回放 |
